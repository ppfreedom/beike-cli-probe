输出格式:
  默认输出单行 JSON（供 Agent 内部解析，不展示原始结果）
  加 --pretty 参数输出表格/纯文本（人工查看）
  加 --json 参数输出完整结构化 pretty JSON（调试用）
  例：beike buy search -c 北京 -q 望京 --pretty

参数说明:
  -c, --city <城市>             城市名称（如：北京、上海、深圳）
  -q, --query <查询词>          自由文本查询条件
  --house-type <类型>           房源类型：second（二手房）| new（新房）| all（默认）
  --id <实体ID>                 房源/小区等实体 ID（可重复指定多个）
  -a, --address <地址>          完整地址文本
  -o, --origin <经纬度>         出发点：经度,纬度 格式（如 116.491,39.996）
  -d, --destination <经纬度>    目的地：经度,纬度 格式
  --date <日期>                 日期格式：YYYY-MM-DD
  --biz <业务类型>              业务类型：二手房 | 新房 | 租房
  --json                        输出原始 JSON（不进行格式化）
  --pretty                      输出表格/纯文本（人工查看）
  --save                        保存 API Key 到本地（auth 命令专用）

常见问题:
  1. Key 存储位置：~/.beike/BEIKE_MCP_API_KEY
  2. Key 来源优先级：BEIKE_MCP_API_KEY 环境变量 > 命令行参数 > 本地文件
  3. 多参数格式："望京 500万以内 两居室改善" 可直接放在 -q 后面
  4. 经纬度格式：GCJ-02（国测局坐标系），即 Google/高德 地图上的坐标
  5. 跨城公交：--city 为起点城市，--cityd 为终点城市
